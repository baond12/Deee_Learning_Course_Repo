## Landing Page

Trang GitHub Pages được đặt ở root:

- `index.html`: trang chủ nhóm, giảng viên, timeline và link E1-E3 / A1 / A2.
- `pages/exercises.html`: khung bài tập E1, E2, E3.
- `pages/assignment1.html`: khung bài tập lớn A1.
- `pages/assignment2.html`: khung bài tập lớn A2.
- `assets/css/styles.css`: style dùng chung.
- `assets/img/course-roadmap.png`: ảnh nền cho trang chủ.

Khi đẩy lên GitHub, bật GitHub Pages với source là branch `main`, folder `/root`.
